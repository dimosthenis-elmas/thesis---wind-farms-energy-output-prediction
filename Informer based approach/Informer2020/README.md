
This repository contains part of the experimentations for my master's degree thesis.

The code is based on the original work by zhouhaoyi on the Informer architecture: https://github.com/zhouhaoyi/Informer2020

Any opinion expressed in this (derivative) repository does not necessarily reflect the view of the original authors nor of any university or any individual.

The contents of this repository reflect my own views and ideas.

I have not included the datasets for the training, just a single line of them in order to give an idea about the formatting.

The datasets can be obtained by refering to the original publishers:
T. Hong, P. Pinson, S. Fan, H. Zareipour, A. Troccoli, and R. J. 2016. «Probabilistic energy forecasting: Global energy forecasting competition 2014 and beyond.» International Journal of Forecasting 32.
J. Dowell, P. Pinson. χ.χ. «Very-short-term Probabilistic Wind Power Forecasts by Sparse Vector Autoregression.» IEEE Transactions on Smart Grid.
